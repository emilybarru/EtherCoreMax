# EtherCoreMax

EtherCoreMax implements High-Performance, Advanced edge computing for real-time data processing, auto-scaling across distributed Node-Agents.

With EtherCoreMax, you get a lightweight tool that stays out of your way.

**What you get**

- computing for real-time data processing,

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/EtherCoreMax.git`
2. `cd EtherCoreMax`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
